# CIFAR-10 Animal/Object Recognizer

This is a team-based AI/ML project focused on building an image classification model using the CIFAR-10 dataset.

## Objective
To develop a Convolutional Neural Network (CNN) that can classify images into 10 categories including animals and objects.

- Google Colab
- PyTorch / TensorFlow
- GitHub
